# ПК Мастер — сайт выездного компьютерного сервиса

Готовый статический сайт для GitHub Pages. Он описывает услуги сервиса и сотрудничество с выездными мастерами, без вымышленных отзывов, рейтингов, адреса офиса, цен или неподтверждённых сведений о штате.

## До публикации — обязательные правки

1. В `index.html` замените `YOUR-DOMAIN.ru` в `rel="canonical"` на собственный домен.
2. Замените `УКАЖИТЕ ТЕЛЕФОН` на реальный номер и обновите `href="tel:+70000000000"` в ссылке кнопки.
3. В JSON-LD в начале `index.html` замените `+7-000-000-00-00` на тот же номер.
4. Проверьте, что перечисленные услуги соответствуют тому, что реально выполняется.

## Публикация на GitHub Pages

1. Откройте https://github.com/ и войдите или создайте аккаунт.
2. Создайте новый репозиторий, например `pc-master-site`. Для GitHub Free выберите `Public`.
3. Нажмите **Add file → Upload files** и загрузите `index.html`, `styles.css`, `favicon.svg`.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, нажмите **Save**.
7. После публикации GitHub покажет адрес сайта.

## Собственный домен .ru

1. Зарегистрируйте домен у регистратора на своё имя.
2. Добавьте домен в **Settings → Pages → Custom domain**.
3. Настройте DNS по официальной инструкции GitHub: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
4. Дождитесь обновления DNS и включите **Enforce HTTPS**, когда опция появится.

## Важно для hh.ru

Сайт описывает сервис, но сам по себе не подтверждает юридический статус или прохождение проверки работодателя. Если hh.ru запросит документы, адрес или подтверждение регистрации, предоставляйте реальные сведения. Не указывайте вымышленный офис, юридическое лицо, штат, отзывы или цены.

Сайт не содержит формы сбора персональных данных и не имеет серверной части.
